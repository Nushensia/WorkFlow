# Промт: Шаблон протокола физико-химического фазового анализа

Создай шаблон документа Microsoft Word (.docx) для **Протокола физико-химического фазового анализа** организации АО «НПО «Ленкор» (Лаборатория разрушающих методов контроля).

## Формат страницы
A4, поля: верхнее 2.0 см, левое 3.0 см, нижнее 2.0 см, правое 1.5 см.

## Рамка (обязательно)
Весь документ должен быть обёрнут в **таблицу из 1 колонки** с видимыми границами. Эта таблица служит рамкой страницы.

**Параметры таблицы-рамки:**
- Количество колонок: 1
- Ширина колонки: ~9309 dxa (auto)
- Границы (tblBorders): top/left/bottom/right — single, sz=18, color=auto (чёрная линия толщиной ~0.75 pt)
- Внутренних границ не требуется (insideH/insideV не нужны)

**Структура таблицы-рамки (2 строки):**

**Строка 0 — Шапка организации:**
Внутри ячейки — вложенная таблица (без границ, все border-элементы имеют w:val="none") на 1 колонку и 2 строки:
- **Строка 0.1 (верхняя)**: содержит **логотип** организации. Логотип берётся из файла `logo_top.png` (размер ~3.5×0.53 см), который находится в папке `Паспорта/Исходные протоколы/`. Выравнивание по левому краю.
- **Строка 0.2 (нижняя)**: содержит информацию о компании — название, лабораторию, аккредитацию, адрес (см. раздел «Шапка»). **Строго по центру на всю ширину страницы** — выравнивание по центру как по горизонтали, так и по вертикали.

Границы вложенной таблицы **отсутствуют** (невидные). Между строкой 0 и строкой 1 рамки — жирная черта (граница insideH таблицы-рамки, sz=18).

## Колонтитул (нижний, footer)
Добавить **нижний колонтитул (footer)** со следующим содержимым:

**Формат:** «ПРОТОКОЛ ФИЗИКО-ХИМИЧЕСКОГО ФАЗОВОГО АНАЛИЗА № [номер]/[индекс]-[год]   Лист X из Y»

Где:
- `ПРОТОКОЛ ФИЗИКО-ХИМИЧЕСКОГО ФАЗОВОГО АНАЛИЗА № [номер]/[индекс]-[год]   Лист` — обычный текст (не жирный)
- `X` — поле **PAGE** (номер текущей страницы) — **полужирный**
- `из` — обычный текст (не жирный)
- `Y` — поле **NUMPAGES** (общее количество страниц) — **полужирный**

**Параметры:**
- Выравнивание по центру
- Шрифт Times New Roman, 10 pt
- Расстояние от нижнего края страницы до колонтитула: ~708 twips (1.25 см)

## Заполнение шаблона из сырых данных

### Источники данных
Сырые данные по карбидному/фазовому анализу хранятся в `Паспорта/Карбидный анализ_сырые данные/` в форматах `.doc` и `.docx`.

### Процесс заполнения
1. Открыть шаблон `Шаблон_протокола_фазового_анализа.docx`
2. Извлечь данные из сырого файла:
   - **п. 1** — заказчик (из шапки сырого файла)
   - **п. 2** — наименование продукции (из описания объекта исследования)
   - **п. 3** — характеристика образца (маркировка образца + электролит)
   - **п. 4** — вид испытаний: «Физико-химический фазовый анализ»
   - **п. 5** — нормативные документы (из раздела «Нормативная документация»)
   - **п. 6** — оборудование (из раздела «Испытательное оборудование»)
   - **п. 7** — количество образцов и даты
   - **п. 8** — результаты: описание фазового состава (текст из раздела «Результаты испытаний»)
3. Таблица фазового состава: заполняется строками из сырых данных (№, Phase name, Chemical formula, Crystal system, Space group, Lattice parameters, DB card number)
4. Рисунок — место для вставки дифрактограммы (не заменяется текстом)
5. Заключение — перечень обнаруженных фаз
6. Подпись — должность и ФИО из исходного протокола-образца
7. Сохранить как `Протокол_[номер]_[электролит].docx`
