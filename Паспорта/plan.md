## Правила проекта

### Общие
1. **Промт — источник истины.** Все изменения сначала в промт, потом в генератор.
2. **Не удалять чужие файлы.** Файлы OpenCode, пользователя и других агентов не трогать.
3. **Согласовывать с пользователем.** Не вносить изменения без явного «да, правь».
4. **Если файл занят Word** — сохранять с суффиксом `_fixed`, потом переименовывать.

### Генерация
5. Шаблон генерировать **только через python-docx API**. Без lxml/ZIP-манипуляций.
6. Footer создавать через `doc.sections[0].footer` с `nsmap={'w': NS_W}` — никаких `ns0:`.
7. Логотип встраивать через `run.add_picture()`.
8. Скрипт: `Паспорта/Шаблоны/generate.py` (основной), `generate_pure.py` (копия).

### Документация
9. **`log.md`** — хронология действий. Каждая запись подписывается: кто сделал (Hermes / OpenCode / пользователь). Добавлять новые записи в конец файла.
10. **`plan.md`** — статус задач и правила проекта (этот файл). Обновлять после каждого действия.
11. **`agent.md`** — описание агента OpenCode. Не редактировать без явного разрешения.

### Skill
12. **`protocol-template-lencor`** — сохранённый скилл с описанием структуры, путей и правил. Загружать в начале новой сессии командой `skill_view(name='protocol-template-lencor')`.
