# Промт: Шаблон паспорта объекта исследования

## Назначение
Создать документ Microsoft Word (.docx) — **Паспорт объекта исследования** по результатам комплекса испытаний. Паспорт объединяет все протоколы по одному заказу в единый структурированный документ без аналитической части (выводы, заключение, рекомендации — это уже отчёт).

## Чем паспорт отличается от отчёта
- **Паспорт** — свод фактов: описание объекта, программа, результаты всех испытаний. Без обсуждения.
- **Отчёт** — паспорт + разделы 4–7 (Обсуждение, Выводы, Заключение, Рекомендации).

## Источники данных
- JSON-карточка заказа: `Заказы/{номер}_{заказчик}/{номер}_данные.json`
- Протоколы испытаний: `Заказы/{номер}_{заказчик}/Протоколы/`
- Входящие документы заказчика
- Эталонный шаблон отчёта: `Отчеты/Шаблон_отчета_фин.docx` (структура разделов 1–3)
- Правила и структура: `Отчеты/OpenCode/AGENTS.md`

## Формат страницы
A4, поля: верхнее 2.0 см, левое 3.0 см, нижнее 2.0 см, правое 1.5 см.
Шрифт: Times New Roman, 12 pt (основной текст).

## Структура паспорта

### Титульный лист
- **УТВЕРЖДАЮ** — Генеральный директор АО «НПО «Ленкор», линия подписи, дата
- **ПАСПОРТ** — крупно, по центру
- `объекта исследования: {наименование_объекта}`
- `Заказчик: {заказчик}`
- `Номер заказа: {номер}`
- `г. Санкт-Петербург, {год}`

### 1. Введение
**1.1 Основание для проведения исследования**  
Договор №___ от ___.___.20__ г.

**1.2 Сведения об экспертной организации**  
АО «НПО «Ленкор», реквизиты, аккредитация.

**1.3 Сведения об экспертах**  
ФИО, должности.

**1.4 Цель исследования**  
Формулируется из задания.

**1.5 Перечень рассмотренной документации**  
Нормативная, конструкторская, технологическая документация.

**1.6 Характеристика объекта исследования**  
Оборудование: тип, назначение, материал (марка, ГОСТ), рабочие параметры (P, T, среда), год ввода, изготовитель.

### 2. Программа исследования
**2.1 Образцы**  
Маркировка вырезок (П-…), материал, количество. Схема вырезки, геометрия (при наличии).

**2.2 Методы исследования**  
Таблица: вид испытания — НТД — оборудование — статус (проведено / отдано в стороннюю org.).

### 3. Результаты исследования

#### 3.1 Анализ документации
Обзор предоставленной заказчиком документации.

#### 3.2 Визуальный и измерительный контроль (ВИК)
Описание внешнего состояния, дефекты, замеры.

#### 3.3 Ультразвуковая толщинометрия (если применимо)
Результаты замеров толщины.

#### 3.4 Химический анализ
Химический состав материала.

#### 3.5 Анализ технологического осадка (по необходимости)

#### 3.6 Металлографическое исследование
**3.6.1 Оптическая микроскопия**  
Структура, неметаллические включения, балл зерна.

**3.6.2 Электронная микроскопия SEM/EDS (если применимо)**  
Микроструктура, элементный состав фаз.

**3.6.3 Микротвёрдость**

#### 3.7 Измерение твёрдости (макро)

#### 3.8 Механические испытания

#### 3.9 Специальные испытания (по необходимости)
- Физико-химический фазовый анализ
- СКРН (SSC) — NACE TM0177
- HIC — NACE TM0284
- Длительная прочность — ГОСТ 10145

Для каждого проведённого испытания указать:
- методику / НТД
- оборудование
- полученные результаты (таблицы, графики, рисунки)
- ссылку на протокол (если есть)

### 4. Заключение (только констатация фактов)
Перечень проведённых испытаний, краткое резюме результатов. Без вердикта.

## Приложения (П-1…П-N)
Нумеровать по типам исследований:
- П-1 ВИК (фото, протоколы)
- П-2 Химический анализ
- П-3 Металлография
- …
- П-N Нормативная документация

## Оформление
- Все таблицы и рисунки — сквозная нумерация
- У каждой таблицы/рисунка — подпись (Таблица 1 — …, Рисунок 1 — …)
- Ссылки на приложения — в тексте каждого раздела
- Если раздел/приложение не применимо — не включать, номера сдвигаются

## Плейсхолдеры
| Плейсхолдер | Описание |
|-------------|----------|
| `{номер}` | Номер заказа (П-XXX) |
| `{заказчик}` | Наименование заказчика |
| `{объект}` | Наименование объекта |
| `{материал}` | Марка материала |
| `{год}` | Год составления |
| `{наименование_объекта}` | Полное наименование для титула |

## Процесс заполнения
1. Прочитать JSON-карточку заказа: какие испытания проведены, какие файлы есть
2. Для каждого испытания с типом «есть» — найти соответствующий протокол
3. Извлечь из протоколов: методику, оборудование, результаты (таблицы, цифры)
4. Заполнить раздел 3 только теми подразделами, которые есть в заказе
5. В разделе 3.9 «Специальные испытания» — перечислить только применённые виды
6. Сформировать приложения
7. Сохранить как `Паспорт_{номер}_{заказчик}.docx`
